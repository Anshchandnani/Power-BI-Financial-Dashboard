# Financial Dashboard \| Power BI

## Overview

The **Financial Dashboard** is my second Power BI dashboard project. It
builds on the concepts I explored in my first dashboard and focuses on
presenting financial data in an interactive, easy-to-understand format.

## Objectives

-   Practise creating a clear and organized Power BI report.
-   Use **slicers** to filter report data dynamically.
-   Explore financial data through interactive visualizations.
-   Improve data presentation and dashboard usability.

## Key Learning

### Slicers in Power BI

Slicers allow users to filter the data displayed in a report by
selecting relevant values. They make the dashboard more interactive and
help users focus on the information they want to analyse.

## Tools Used

-   Microsoft Power BI
-   Microsoft Excel (dataset)

## Project Files

-   `Financial_Dashboard.pbix` --- Power BI report file.
-   `DataSet.xlsx` --- source dataset used for the dashboard.

## How to View the Dashboard

1.  Download or clone this repository.
2.  Open `Financial_Dashboard.pbix` using Microsoft Power BI Desktop.
3.  If Power BI asks for the source file, update the data source path to
    `DataSet.xlsx`.
4.  Use the available slicers to interact with the report.
